| R13 | EXIF 拍摄时间按 **JVM 默认时区**解释(单时区家庭 NAS),可配置时区留 M5 | 时间线跨日/月偏 8 小时 |
| R14 | MP4 解析加固(跳读上限前置、`mvhd` 长度校验、未知版本拒绝、溢出/零时长→null) | 垃圾输入被当作已知时长 |
| R15/R16 | 缩略图方向/镜像像素级用例;前端按**本地日期**分组、时间用本地时区 | 缩略图方向错误/分组错位 |
| R17 | `media.thumb` 先读 EXIF Orientation 再渲染 | 手机竖拍缩略图横躺 |
| R18 | 上传完成后**提交后**入队扫描(`afterCommit` + `REQUIRES_NEW`),失败不影响上传 | 回滚污染/扫描读到未提交版本 |
| R19 | `openVersion` 惰性开流(避免大视频 FD 爆炸) | EMFILE 致扫描失败 |
| R20 | 共享工作区提交协议(`--only` + `git show --stat` 核验) | 误提交他人改动 |
| R21 | 不为可见性给 `FilesService` 加 `canRead`(包环) | ArchUnit 失败 |
| R23/R24 | 时间线剪枝回收站子树(含 ACL 授权根的祖先链);ADMIN 可见全部顶层 | 删除后仍出现在时间线 / ADMIN 口径不一致 |

| R31 | ACL 授权根的**列表**不折叠后代 DENY/inherited(单向"可见但打开 404"),M5 共享 UI 时收敛 | 罕见场景信息暴露(名称/时间/尺寸) |

## 4. 已接受边界与延后项

- HEIC/HEIF/WEBP/AVIF 与视频**缩略图**为 `SKIPPED`(纯 Java 路线),M5 引入 ffmpeg 后补齐;视频无封面帧。
- 时间线月桶/相册按 **PostgreSQL 会话时区**分组(与 EXIF 本地墙上时间一致);跨时区部署会整体偏移。
- 日期相册月份为**静态展示**,无月份筛选/年-月跳转(`api/media.ts#listBuckets` 保留为 M5 接口)。
- `/content` 取节点**最新版本**字节,详情/缩略图绑定**索引版本**,覆盖写后未重扫前可能短暂不一致。
- `taken_at_source=MTIME` 实际为版本创建时间(上传时间),非文件 mtime。
- HEIC 改名 JPG 后 reindex 仍为 `SKIPPED`(状态不随扩展名变化重算)。
- 验收脚本的 "MP4" 为占位字节、月桶断言覆盖单月(真实时长/跨月分桶由单元/集成测试覆盖)。
- MockMvc 异步流式与安全头存在极少数偶发(见 `docs/progress.md` 已知限制),重跑即可。
- 各任务评审的逐条 deferred minors 见 SDD 账本(未入库),已按"不阻塞合并"分类。
